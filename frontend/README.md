# Portfolio Frontend

Deploy this folder to Netlify. Build command: `npm install && npm run build`; publish directory: `dist`.

Set Netlify environment variable `VITE_API_URL` to the Render backend base URL without `/api`, e.g. `https://your-api.onrender.com`. The frontend uses `/api` relative to that base URL.

See `../README-DEPLOYMENT.md` for complete setup.
