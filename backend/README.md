# Portfolio Backend

Deploy this folder as a Render Web Service. Build command: `npm install`; start command: `npm start`.

Configure `FRONTEND_URL` with your Netlify site origin and configure MySQL using `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE`, or `MYSQL_URL`.

The API creates tables but does not seed demo portfolio data or create a default administrator. See `../README-DEPLOYMENT.md`.
